# Invoice Billing Management System 💼

A Java-based project to manage invoices, customers, and billing efficiently.

## 🧩 Features
- Add, view, and manage products
- Generate invoices for customers
- Calculate total bill with taxes
- Simple console-based interface

## 🛠️ Technologies Used
- Java (Core)
- OOP Concepts (Classes, Objects, Methods)
- GitHub Codespaces / VS Code for execution

## 🚀 How to Run
1. Open this repository in **GitHub Codespaces** or clone it.
2. Compile and run the Java files:
javac Main.java
java Main
